COMPARISON METRICS
================================================================================

1. Voucher Type Match (25% weight)
   - Exact string match
   - Sales, Journal, Purchase, Receipt, Credit Note

2. Ledger Names Match (35% weight)
   - Exact string match of all ledger names
   - Sorted comparison for order independence
   - Partial credit for partial matches

3. Amount Match (30% weight)
   - Within ₹1 tolerance for rounding
   - Uses total debit amount
   - Partial credit for amounts within 5%

4. Narration Pattern Match (10% weight)
   - Extracts invoice numbers (priority)
   - Fuzzy word similarity (80% threshold)
   - Case and whitespace normalization

MATCHING STRATEGY
================================================================================

Priority 1: Invoice Number Match
- Patterns: 25-26/####, INVOICE NO:-25-26/####, INV: 25-26/####
- Extracts from narration, reference, voucher number
- Confidence: High

Priority 2: Amount + Date Match
- Amount within ₹1
- Date within ±3 days
- Confidence: Medium

Priority 3: Highest Similarity Score
- Compares all remaining vouchers
- Uses weighted scoring
- Confidence: Low (requires manual review)
