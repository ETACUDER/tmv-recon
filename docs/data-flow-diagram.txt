================================================================================
KEY RELATIONSHIPS
================================================================================

1. UPI → BANK (Direct join - 95% accuracy)
   ─────────────────────────────────────────
   Payment.utr_no = BankTxn.utr_no
   Payment.settled_amount = BankTxn.credit_amt
   
   CRITICAL: Must aggregate UPI first!
   ✓ GROUP BY utr_no because 93% duplicates
   
   Example:
   UPI row 1:  UTR=YESAP123, Amount=500
   UPI row 2:  UTR=YESAP123, Amount=200  
   UPI row 3:  UTR=YESAP123, Amount=300  → SUM = 1000
   Bank row:   UTR=YESAP123, Credit=1000 ✓ MATCH

2. INVOICE → AGODA (Fuzzy join - 80% accuracy)
   ──────────────────────────────────────────
   UPPER(REPLACE(Invoice.guest_name, 'Mr.|Mrs.', '')) 
     SIMILARITY > 0.8
   Invoice.arrival_date = Booking.checkin_date
   Invoice.gross_amount ≈ Booking.invoice_amt (±5%)
   
   Example:
   Invoice: "Mr.Nikhil Jat", 2025-04-05, 10999
   Agoda:   "NIKHIL JAT",    2025-04-05, 10950  ✓ MATCH (similarity=0.95)

3. AGODA → BANK (Fuzzy join - 70% accuracy)
   ─────────────────────────────────────────
   Booking.from_agoda BETWEEN BankTxn.credit_amt * 0.99 AND * 1.01
   BankTxn.txn_date BETWEEN Booking.checkin_date - 7 AND + 30
   
   Example:
   Agoda: From Agoda=11687.12, Checkin=2025-07-03
   Bank:  Credit=11687.12, Date=2025-07-05  ✓ MATCH (within range)

NORMALIZATION REQUIREMENTS
================================================================================

1. Column Headers (AGODA)
   ───────────────────────
   INVOICE NO.  ┐
   INVOCIE NO.  ├─→ invoice_no
   INVOICE  NO. ┘
   
   COMM + GST ┐
   COMM+GST   ├─→ commission_gst
   COMM +GST  ┘

2. Guest Names
   ───────────
   "Mr.Nikhil Jat"    ──→ "NIKHIL JAT"
   "Mrs. Priya Kumar" ──→ "PRIYA KUMAR"
   "indrajeet tiwari" ──→ "INDRAJEET TIWARI"
   
   Rules: UPPER() + strip titles (Mr./Mrs./Ms./Dr./Prof.)

3. Dates
   ──────
   AGODA:   "7/3/2025 12:00:00 AM"  ──→ 2025-07-03
   BANK:    "01/07/2025"             ──→ 2025-07-01
   UPI:     "'2025-07-01 08:48:19'" ──→ 2025-07-01
   INVOICE: "2025-03-27"             ──→ 2025-03-27

4. Amounts
   ────────
   "11687.12"     ──→ 11687.12
   "470414.15CR"  ──→ 470414.15
   "35,997.98"    ──→ 35997.98

5. UTR Numbers
   ────────────
   "'YESAP51833296492'" ──→ "YESAP51833296492"
   " YESBN12025... "    ──→ "YESBN12025..."
